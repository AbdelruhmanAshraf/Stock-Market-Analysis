# Stock Market Analysis

This project analyzes the performance of major tech stocks and compares them to the S&P 500 index using Python, pandas, yfinance, and Plotly. It includes:
- Data download and cleaning
- Normalization and comparative analysis
- Annualized return and volatility calculations
- Portfolio performance vs benchmark

## Files
- `stockmarketanalysis.ipynb`: Main analysis notebook

## How to Run
1. Install requirements: `pip install yfinance plotly pandas`
2. Open the notebook and run cells sequentially.
